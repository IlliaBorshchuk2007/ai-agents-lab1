# Завдання для реалізації HTTP API

## Мета

Створити API для каталогу навчальних відео відповідно до специфікації та плану.

## Список завдань

- [ ] 1. Створити папки `app` і `tests`.
- [ ] 2. Встановити бібліотеки FastAPI, Uvicorn, Pydantic і Pytest.
- [ ] 3. Створити модель відео з полями `title`, `topic`, `duration_minutes`.
- [ ] 4. Реалізувати перевірку правильності даних.
- [ ] 5. Реалізувати `POST /videos` для ручного додавання відео.
- [ ] 6. Реалізувати `GET /videos` для отримання списку відео.
- [ ] 7. Створити `app/ai.py` для роботи з Groq API.
- [ ] 8. Реалізувати `POST /videos/ai` для створення відео за текстовим описом.
- [ ] 9. Забезпечити відмову в збереженні неповних або неправильних даних.
- [ ] 10. Написати автоматичні тести в `tests/test_api.py`.
- [ ] 11. Створити `notebooks/02_api_verification.ipynb` для перевірки API.
- [ ] 12. Оновити `README.md` з інструкцією запуску.
- [ ] 13. Перевірити роботу програми та зберегти зміни в Git.

## Критерії завершення

- API запускається без помилок.
- Можна додавати та переглядати навчальні відео.
- Некоректні дані не зберігаються.
- ШІ не додає відео з відсутніми обов'язковими полями.
- Автоматичні тести проходять успішно.
- Результати перевірки API задокументовані.
