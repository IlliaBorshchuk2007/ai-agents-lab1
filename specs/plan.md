# План реалізації HTTP API

## 1. Технології

- Python — мова програмування.
- FastAPI — створення HTTP API.
- Pydantic — перевірка правильності даних.
- Groq API — використання мовної моделі.
- Pytest — автоматичне тестування.

## 2. Структура проєкту

- `app/main.py` — основний код HTTP API.
- `app/ai.py` — робота зі штучним інтелектом.
- `tests/test_api.py` — автоматичні тести.
- `notebooks/02_api_verification.ipynb` — перевірка API.
- `specs/` — специфікація, план і завдання.

## 3. Етапи реалізації

1. Створити структуру проєкту.
2. Реалізувати модель навчального відео з перевіркою даних.
3. Додати `POST /videos` для ручного створення.
4. Додати `GET /videos` для перегляду списку.
5. Підключити Groq до `POST /videos/ai`.
6. Забезпечити відмову в додаванні неповних або неправильних даних.
7. Написати автоматичні тести.
8. Перевірити API через Jupyter Notebook.
9. Оновити README та зберегти зміни в Git.

## 4. Очікуваний результат

Працюючий HTTP API, який дозволяє створювати та переглядати навчальні відео, використовує ШІ для обробки тексту й не зберігає некоректні дані.
