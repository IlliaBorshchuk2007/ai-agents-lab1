# Специфікація API навчальних відео

## Мета
Створити HTTP API для каталогу навчальних відео.

## Поля відео
- `title` — назва, непорожній рядок.
- `topic` — тема, непорожній рядок.
- `duration_minutes` — додатне ціле число.

## Функції API
- `POST /videos` — додавання відео вручну.
- `GET /videos` — отримання списку відео.
- `POST /videos/ai` — створення відео з тексту за допомогою ШІ.

## Правила
- Усі три поля обов'язкові.
- Тривалість повинна бути більшою за нуль.
- ШІ не може вигадувати відсутні дані.
- Якщо інформації недостатньо, потрібно попросити уточнення.
- Некоректні дані не зберігаються.

## Зберігання
Відео зберігаються у списку Python у пам'яті програми.
